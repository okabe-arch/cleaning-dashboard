# 定期美化清掃 管理ボード

喫煙室の定期美化清掃（約6ヶ月周期）を **月ごと** に管理する、単一ファイル完結の
ダッシュボードです。`index.html` を開くだけで動作します（サーバ不要・ビルド不要）。

## 物件マスタ

**207件**を組み込んでいます。出典は次の3つです。

| 出典 | 内容 |
|---|---|
| 定期清掃リスト（更新版26年6月更新） | 物件名・THE TOBACCOコード・エリア・住所・自社担当・**清掃時期**・周期・作業届の要否とファイル名・作業可能時間・脚立レンタル |
| 2026定期清掃依頼リスト／担当調整中 | **外部委託（COSOJI）の対象かどうか**・広さ |
| メールの往来 | 上記に無い物件（野村不動産広島ビル・NMF博多駅前ビル・PMO EX本町・PMO梅田） |

現状の内訳は 🏢 自社 **67件** ／ 🤝 委託 **124件** ／ ⏳ 担当調整中 **16件** です。

**届け先の担当者名・メール・電話・備考・委託先の担当クルー名は個人情報のためファイルに含めていません。**
「物件・連携」タブの［📗 Excelを読み込む］で、**この端末の中だけ**に取り込みます
（ブラウザ内で解析し、どこにも送信しません）。リストを更新したら読み込み直せば追従します。

### 委託かどうかの見分け方

すべてのカード・物件一覧・送信画面に実施体制のタグが出ます。

- 🏢 **自社** — 自社で実施
- 🤝 **委託COSOJI** — 外部委託（取り込み済みなら担当クルー名も表示）
- ⏳ **担当調整中** — 実施担当が未確定（アラートにも出ます）

ボードと物件一覧には「自社／委託／担当調整中」の絞り込みがあります。
同一日の作業重複アラートは**自社実施分のみ**を対象にします（委託分は委託先が手配するため）。

## できること

| | 内容 |
|---|---|
| 月ごと管理 | `YYYY-MM` 単位で案件を管理。月セレクタで切替、前月の未完了をコピー |
| 清掃時期からの自動立ち上げ | 原本の「清掃時期（例：1月・7月）」から、その月の実施予定物件を一括登録。作業時間欄に日付があれば作業予定日と期限も自動で入る |
| Excelの取り込み | .xlsx をページ内で解析し、届け先・備考・清掃時期・**委託の別**を更新（外部ライブラリ不要／複数ファイル同時可） |
| 6ヶ月周期の自動繰越 | 完了報告を記録すると、周期後の月に次回案件を自動作成 |
| 受信メールで自動更新 | メール本文を貼り付ける／ドロップすると、物件・工程・作業日・時間帯・次回予定を自動抽出して反映 |
| Gmail 自動連携 | Apps Script（同梱・読み取り専用）を置くと、貼り付けなしで定期的に自動取込 |
| 送信メールの自動生成 | 工程に応じた文面（事前確認／日程打診・作業届／催促／完了報告）を生成。送信記録で工程が自動で進む |
| 見落とし防止 | 期限超過、未承認のまま作業日接近、作業済み・報告未送付、同一日の重複、連携停止を警告 |
| 監査ログ | 自動更新の履歴を保持。直前の自動反映は「元に戻す」で取消可能 |

## 工程

```
0 未着手 → 1 事前確認 送付済 → 2 条件回答 受領 → 3 日程打診・作業届 提出済
        → 4 承認済・日程確定 → 5 作業完了 → 6 完了報告 送付済 →（+周期ヶ月）0
```

工程は後退しません。古いメールを後から取り込んでも確定情報は壊れません。

## 使い方

1. `index.html` をブラウザで開く（PC / スマートフォン、ダークモード対応）
2. 「物件・連携」タブで［📗 Excelを読み込む］→ 原本リストと委託リストをまとめて選択。届け先の担当者と委託の別が入る。あわせて差出人（担当者名）を設定
3. ボードの緑のバー［一括登録］で、その月に予定されている物件をまとめて登録
4. 受け取ったメールを「受信取込」に貼り付け → 工程・日程が自動で入る
5. 「送信」タブから文面を生成 → Gmail で送信 → 「送信済みにする」を押す

### Gmail 自動連携（任意）

「物件・連携」タブの手順に従って Google Apps Script を配置します。
スクリプトは Gmail を **読み取るだけ** で、送信・削除・下書き作成は行いません。

> **注意**: ブラウザから取得するため、デプロイのアクセス設定は「全員」にし、
> スクリプト内の `SHARED_KEY` による保護を使います。
> **連携URL（キーを含む）を知っている人は対象メールを読めます。社外に共有しないでください。**

## データの保存

- 保存先は **そのブラウザの localStorage のみ** です（サーバに送信しません）
- キャッシュ削除・端末変更・プライベートモードで失われます
- 「物件・連携」タブの **バックアップを書き出す** で定期的に保管してください
  （14日以上経つと画面上で催促します）
- 「共有URL」は表示中の月を deflate 圧縮して URL に載せます（50件で約1,600文字）
- Excelそのものは保存しません。読み込んだ内容（担当者・備考・委託の別など）のみが localStorage に入ります
- 委託リストは毎月更新される前提で、読み込むと委託指定を一度リセットして付け直します。
  リストから外れた物件は自動的に「自社」に戻ります。外れる件数が多いときは確認ダイアログが出ます

## 安全側に振っている挙動

- 自動送信は行いません。送信は必ず人がGmailで実行します
- 自動反映は工程4（日程確定）までです。工程5・6（作業完了・完了報告）は、
  Gmailの送信済みラベルで自社送信と確認できた場合のみ自動、それ以外は人が確認します
- 「承知しました」等の常套句は、日付を伴わなければ承認と判定しません
- 否定・延期の表現があるメールは承認と判定しません
- 差出人は表示名ではなくアドレス部で判定します（なりすまし対策）
